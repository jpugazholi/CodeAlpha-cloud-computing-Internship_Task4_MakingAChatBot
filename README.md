# 🤖 Nova AI - Smart Chatbot

## 📌 Project Overview

Nova AI is a retrieval-based AI chatbot developed as part of the CodeAlpha Cloud Computing Internship - Task 4.

The chatbot provides instant responses to common user queries using predefined patterns and keyword-based retrieval. It is integrated into a responsive website with an attractive and user-friendly interface.

## ✨ Features

- 🤖 Retrieval-based AI chatbot
- 💬 Instant responses
- 🔎 Keyword and pattern-based matching
- 👋 Greeting and small-talk support
- 💼 Services information
- 💰 Pricing information
- 🕐 Working hours
- 📞 Contact information
- 📍 Location information
- 🆘 Customer support
- 😂 Joke support
- ⭐ Feedback handling
- ❓ Smart fallback responses
- ⚡ Typing indicator
- 💾 Chat history using LocalStorage
- 🗑️ Clear chat functionality

- 📱 Responsive design

- CSS3
- JavaScript
- LocalStorage

## 🧠 Chatbot Approach

This project uses a retrieval-based chatbot approach.

The user's input is normalized and matched with predefined keywords and patterns. Based on the detected intent, the chatbot retrieves and displays the appropriate response.

This approach provides fast and predictable responses without requiring an external AI API.

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click the "Chat with us" button.
5. Start chatting with the AI assistant.
